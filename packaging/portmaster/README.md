# Prince of Persia 2 (PortMaster)

Prince of Persia 2: The Shadow and the Flame, the 1993 Macintosh version, as a native
program (the original translated to C; unofficial). Source: https://github.com/dmucli/pop2-port

## Game files

Copy the disk image of **your own** copy of the Macintosh version into `ports/pop2/`: any
name, `.hfv`, `.dsk`, `.img`, `.image`, `.toast`, `.iso`, `.cdr` or `.bin`. No game data is
included.

## Controls

| Pad | |
| --- | --- |
| D-pad / left stick | move |
| A / B | action / second button |
| Start | pause; on the title screen, start a game |
| Select | time left |
| Hotkey + B | extras menu: save states with pictures, go to level, cheats, display, statistics |
| Hotkey + Y / X | save state / load the newest |
| Hotkey + Left (hold) | rewind |
| Hotkey + Up / Right | one more health / 5 more minutes |
| Hotkey + Start | quit |

Saves, save states, settings and the log: `ports/pop2/saves` (and `ports/pop2/log.txt`).
